# ZWF UI Kit Generator (Figma plugin)

Локальний плагін для Figma. Він будує UI Kit у файлі дизайну з **трьох окремих фреймів**: «Кольори», «Типографіка» і «Компоненти». У кожному фреймі **світла й темна теми стоять поруч**, а кожен компонент зібраний як **один набір варіантів** зі станами.

## Що створює плагін

| Що | Деталі |
|---|---|
| Змінні `ZWF / Color` | 34 кольори з режимами **Light / Dark**. Значення взято з `packages/ui/src/styles/theme.css` і `index.css` (`.dark`). Code syntax: `var(--color-…)` |
| Змінні `ZWF / Radius` | `radius/sm…pill` (6 / 8 / 12 / 16 / 9999) |
| Текстові стилі `ZWF/…` | Display, Heading H1–H3, Body, Label, Caption (Inter) |
| Стилі ефектів `ZWF/…` | Shadow Card / Raised / Modal / Pressed (inner), Focus ring |
| Набори компонентів | **Button** (Variant × State × Size = 72), **Input** (Type × State = 15), **Checkbox** (6), **Chip** (3), **Badge** (Tone × Dot = 12), **FreshnessBadge** (4), **StatCard** (3), **Card** |
| Сторінка `🧩 UI Kit` | Три фрейми поруч: **Кольори** (палітра за групами), **Типографіка** (усі текстові стилі), **Компоненти** (радіуси й тіні + усі набори компонентів). У кожному ліворуч колонка **Light**, праворуч **Dark**. Майстер-компоненти живуть у колонці Light фрейму «Компоненти», у колонці Dark — їхні екземпляри |

Властивості компонентів:
- Button: `Label` (текст) і `Icon` (так/ні).
- Input: `Label`, `Helper text` і `Helper`.
- Chip: `Label` і `Count`.
- Badge: `Label`.

## Як запустити

Потрібен **Figma Desktop**: у браузерній версії не можна імпортувати плагін для розробки.

1. Відкрийте файл дизайну в Figma Desktop.
2. Меню **Plugins → Development → Import plugin from manifest…** (або правий клік на полотні → Plugins → Development).
3. Виберіть файл `tools/figma-ui-kit/manifest.json` з цього репозиторію. Імпортувати треба лише один раз.
4. Запустіть **Plugins → Development → ZWF UI Kit Generator**.
5. Зачекайте 10–30 секунд. Унизу з'явиться повідомлення «UI Kit готовий: 8 компонентів, 116 варіантів…», і Figma перейде на сторінку `🧩 UI Kit`.

Наступні запуски: **Plugins → Development → ZWF UI Kit Generator** або `⌘ + ⌥ + P` (Run last plugin).

## Після запуску

1. Перевірте сторінку `🧩 UI Kit`. Перемикач теми для будь-якого фрейму: панель праворуч → **Layer → Apply variable mode → ZWF / Color → Light / Dark**.
2. Видаліть старі сторінки або фрейми з двома окремими UI Kit. Плагін їх не чіпає.
3. За бажанням опублікуйте бібліотеку: **Assets → Libraries → Publish**. Тоді компоненти будуть доступні в інших файлах.

## Тариф Figma і режими

На **Starter** у колекції змінних може бути лише один режим. Плагін це визначає сам:
- створює окрему колекцію `ZWF / Color (Dark)`;
- у колонці Dark перепривʼязує кольори до неї.

Результат виглядає так само. Але для нових макетів темна тема тоді не вмикається одним перемикачем режиму.

Щоб отримати повноцінні режими, підійде **Figma for Education**: це безкоштовний Professional для студентів, заявка на figma.com/education. Після оновлення тарифу запустіть плагін ще раз. Він додасть режим Dark до `ZWF / Color`, а колонка Dark перейде на нього.

## Повторний запуск

- Змінні та стилі оновлюються за назвою, без дублікатів. Якщо змінили токени в коді, оновіть масиви `COLOR_TOKENS`, `TYPE_TOKENS` тощо в `code.js` і запустіть плагін знову.
- Фрейми на сторінці `🧩 UI Kit` перебудовуються з нуля. **Екземпляри компонентів, уже вставлені в макети, після цього втратять звʼязок з майстер-компонентами.** Тому перезапускайте плагін до того, як почнете використовувати компоненти в екранах, або опублікуйте бібліотеку й оновлюйте її вручну.
